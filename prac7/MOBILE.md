# Allan's Car Counter — mobile companion

**For markers:** Android install for the Practical 7 phone demo.

| | |
|--|--|
| App name | Allan's Car Counter |
| Package | `com.allans.car_counter` |
| Model | SSD MobileNet v1 TFLite (on-device) |
| Classes | bicycle, car, motorcycle, bus, truck |
| Source | `allans-car-counter/` (sibling folder; own git repo) |

## Install on Android

1. Transfer **`prac7/apk/Allans_Car_Counter.apk`** to the phone  
   (same file also under `APK_FOR_PHONE/Allans_Car_Counter.apk`).
2. Open the file on the phone → Install (enable “unknown sources” if asked).
3. Launch **Allan's Car Counter** → allow camera → point at traffic.

## Blindspot

Blindspot is a **separate** accessibility project. Vehicle counting for this capstone is only in Allan's Car Counter + the Streamlit/Gradio web demo.
